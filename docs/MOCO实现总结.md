## 📊 对比分析

| 特性 | MoCoV2MultiView | EnhancedMoCoV2MultiView |
|------|-----------------|------------------------|
| **核心思想** | 基础MoCo v2多视图 | 增强版门控队列 |
| **队列管理** | 环形队列，FIFO更新 | 门控权重队列，智能筛选 |
| **温度控制** | 固定温度T | 自适应温度，基于统计 |
| **负样本权重** | 统一权重 | 动态权重，基于相似度和年龄 |
| **更新策略** | 简单动量更新 | GRU式门控更新 |
| **计算复杂度** | O(B×K) | O(B×K) + O(B×K×3) |
| **内存使用** | 基准 | 基准 + 门控网络 |
| **适用场景** | 标准对比学习 | 复杂环境，噪声数据 |

## 🚀 使用方式

### 命令行配置

```bash
# 基础使用
python main.py --moco_type basic

# 增强使用
python main.py --moco_type enhanced

# 高级配置字符串
python main.py --moco_config "enhanced[K=8192,gate_hidden=128,prune_threshold=0.0001]"

# 分参数配置
python main.py \
    --moco_type enhanced \
    --moco_gate_hidden 128 \
    --moco_prune_threshold 1e-4 \
    --moco_decay_factor 0.99
```

### 代码中使用

```python
from layer import MoCoFactory

# 工厂模式创建
moco_basic = MoCoFactory.create_moco(
    base_dim=256,
    proj_dim=128,
    num_views=3,
    config_str="basic[K=4096,m=0.999]"
)

moco_enhanced = MoCoFactory.create_moco(
    base_dim=256,
    proj_dim=128,
    num_views=3,
    config_str="enhanced[gate_hidden=64,prune_threshold=1e-3]"
)
```

## 🔧 技术细节

### 基础MoCo特性
- **多视图支持**: 统一查询(q)，多个键(k)
- **队列机制**: 环形队列，固定大小
- **动量更新**: 编码器参数的动量更新
- **温度缩放**: 固定温度参数

### 增强MoCo特性
- **门控权重**: 基于相似度和年龄的动态权重
- **自适应温度**: 基于统计特征的温度调整
- **GRU更新**: 门控单元式的权重更新
- **向量计算**: 全量向量化操作，避免循环

### 工厂模式优势

- **错误处理**: 优雅的回退和错误处理

## 🎯 使用建议

### 选择基础MoCo的场景
- 标准对比学习任务
- 计算资源有限
- 初步实验和快速原型
- 大规模训练需要高效率

### 选择增强MoCo的场景
- 数据分布复杂或噪声较多
- 需要精细控制负样本权重
- 研究对比学习的边界情况
- 对性能要求较高的任务

### 参数调优建议
1. **队列大小**: 小数据集用1024-2048，大数据集用4096-8192
2. **门控参数**: 简单任务用32-64，复杂任务用128-256
3. **温度参数**: 标准情况0.1-0.2，困难任务0.05-0.1
4. **剪枝阈值**: 噪声数据减小阈值，干净数据可适当增大
