# 三实体协作注意力使用指南

## 概述

EM模型现已支持三实体协作注意力机制，可以在原有的两实体融合基础上扩展到三个实体的复杂关系建模。

### 🎯 新增功能

1. **三实体融合策略**
   - `TriSelfAttentionFusion` - 三实体自注意力融合
   - `TriCoAttentionFusion` - 三实体协作注意力融合

2. **热插拔支持**
   - 运行时动态切换三实体融合策略
   - 与现有两实体策略完全兼容

3. **向后兼容**
   - 不启用三实体模式时，系统行为完全不变
   - 现有命令行参数和接口保持一致

## 命令行使用方法

### 基本语法
```bash
python main.py --tri_entity_mode <true|false> [tri_entity_options] [existing_options]
```

### 三实体模式参数

#### 启用三实体模式
```bash
# 基本三实体模式（默认三实体自注意力）
python main.py --tri_entity_mode True

# 三实体协作注意力模式
python main.py --tri_entity_mode True --tri_fusion_strategy tri_co_attention

# 三实体自注意力模式
python main.py --tri_entity_mode True --tri_fusion_strategy tri_self_attention
```

#### 兼容两实体模式
```bash
# 两实体模式（默认行为，完全向后兼容）
python main.py
python main.py --tri_entity_mode False

# 两实体模式可以使用原有的融合策略
python main.py --fusion_strategy co_attention --tri_entity_mode False
python main.py --fusion_strategy hybrid --fusion_weight 0.7 --tri_entity_mode False
```

### 新增参数说明

| 参数 | 可选值 | 默认值 | 说明 |
|------|--------|--------|------|
| `--tri_entity_mode` | `True`, `False` | `False` | 是否启用三实体融合模式 |
| `--tri_fusion_strategy` | `tri_self_attention`, `tri_co_attention` | `tri_self_attention` | 三实体融合策略类型 |
| `--co_hidden_dim` | `正整数` | `None` | 协作注意力的隐藏维度 |

## 完整示例

### LDA任务 - 三实体模式
```bash
# 三实体自注意力融合的LDA任务
python main.py \
  --task_type LDA \
  --tri_entity_mode True \
  --tri_fusion_strategy tri_self_attention \
  --epochs 100 \
  --lr 1e-4

# 三实体协作注意力融合的LDA任务
python main.py \
  --task_type LDA \
  --tri_entity_mode True \
  --tri_fusion_strategy tri_co_attention \
  --co_hidden_dim 128 \
  --epochs 100 \
  --lr 1e-4
```

### MDA任务 - 三实体模式
```bash
# 三实体协作注意力的MDA任务
python main.py \
  --task_type MDA \
  --tri_entity_mode True \
  --tri_fusion_strategy tri_co_attention \
  --epochs 150 \
  --lr 2e-4 \
  --hidden1 256 \
  --hidden2 128
```

### 混合使用场景

```bash
# 两实体模式 + 协作注意力
python main.py \
  --tri_entity_mode False \
  --fusion_strategy co_attention \
  --co_hidden_dim 128

# 三实体模式 + 自注意力
python main.py \
  --tri_entity_mode True \
  --tri_fusion_strategy tri_self_attention

# 三实体模式 + 协作注意力
python main.py \
  --tri_entity_mode True \
  --tri_fusion_strategy tri_co_attention \
  --co_hidden_dim 256
```

## 技术架构

### 🏗️ 模型组件

#### 新增类层次
```
TriFusionStrategy (抽象基类)
├── TriSelfAttentionFusion
├── TriCoAttentionFusion
└── TriGraphTransformerStyleFusion (支持热插拔)

TriFusionDecoder (三实体融合解码器)
TriPairwiseCoAttention (三方协作注意力)
```

#### EM模型集成
```
EM
├── encoder: GATGTSerial (共用）
├── fusion: Union[FusionDecoder, TriFusionDecoder]
│   ├── 两实体模式: FusionDecoder
│   └── 三实体模式: TriFusionDecoder
├── moco: MoCoV2MultiView (共用）
└── adv_head: Linear (共用）
```

### 🔄 热插拔机制

三实体融合策略支持运行时动态切换：
```python
# 在训练过程中切换策略
model.tri_fusion.set_tri_fusion_strategy("tri_co_attention")
model.tri_fusion.set_tri_fusion_strategy("tri_self_attention")
```

## 故障排除

### 常见问题

**Q: 三实体模式下训练速度变慢**
A: 三实体融合需要更多计算，这是正常的。可以尝试：
- 减少 `hidden2` 维度
- 使用 `tri_self_attention` 策略（比 `tri_co_attention` 快）

**Q: 三实体抽取索引错误**
A: 检查数据集是否包含足够的三元组。三实体模式需要三个实体索引：
```python
idx = [entity1_idx, entity2_idx, entity3_idx]  # 需要三个索引
```

**Q: 内存不足**
A: 三实体模式内存使用约为两实体模式的1.5倍：
- 减小批大小 `--batch`
- 降低维度 `--hidden1`, `--hidden2`

**Q: 策略切换无效**
A: 确保在正确的模式下：
- 两实体策略：`--tri_entity_mode False`
- 三实体策略：`--tri_entity_mode True`

## 最佳实践

### 🎯 何时使用三实体模式
1. **复杂关系建模**: 当三个实体间存在复杂交互关系时
2. **图神经网络增强**: 需要更丰富的实体表示交互
3. **实验研究**: 对比两实体和三实体融合效果差异

### 💡 性能优化建议
1. **渐进式启用**: 先用两实体模式训练，再启用三实体模式
2. **维度平衡**: 三实体模式下建议适当减少隐藏维度
3. **策略选择**: `tri_self_attention` 通常更快，`tri_co_attention` 更适合强关联

### 🔄 模型迁移
从两实体迁移到三实体模式：
```bash
# 原有命令
python main.py --fusion_strategy hybrid --fusion_weight 0.7

# 迁移到三实体
python main.py --tri_entity_mode True --tri_fusion_strategy tri_self_attention
```
