# EM模型融合策略使用指南

## 概述

EM模型支持三种融合策略，可通过命令行参数灵活选择和配置：

1. **SelfAttentionFusion** - 原始自注意力融合
2. **CoAttentionFusion** - 协作注意力融合  
3. **HybridFusion** - 混合融合策略

## 命令行使用方法

### 基本语法
```bash
python main.py --fusion_strategy <strategy> [strategy_specific_options]
```

### 策略详情

#### 1. 自注意力融合 (SelfAttentionFusion)
使用原始的Graph Transformer风格自注意力机制。

```bash
# 使用自注意力融合（默认策略）
python main.py --fusion_strategy self_attention

# 或者直接运行（默认就是self_attention）
python main.py
```

#### 2. 协作注意力融合 (CoAttentionFusion)
使用双向协作注意力机制，实现两个实体间的相互关注。

```bash
# 基本协作注意力
python main.py --fusion_strategy co_attention

# 指定协作注意力的隐藏维度
python main.py --fusion_strategy co_attention --co_hidden_dim 128
```

**参数说明：**
- `--co_hidden_dim`: 协作注意力的隐藏维度，None时使用输入维度

#### 3. 混合融合策略 (HybridFusion)
结合自注意力和协作注意力的优势，通过权重平衡两种策略。

```bash
# 基本混合策略（默认权重0.5）
python main.py --fusion_strategy hybrid

# 调整自注意力权重为0.7（协作注意力0.3）
python main.py --fusion_strategy hybrid --fusion_weight 0.7

# 调整自注意力权重为0.3（协作注意力0.7）
python main.py --fusion_strategy hybrid --fusion_weight 0.3
```

**参数说明：**
- `--fusion_weight`: 自注意力的权重 (0.0-1.0)
  - 0.0: 完全使用协作注意力
  - 0.5: 自注意力和协作注意力各占50%
  - 1.0: 完全使用自注意力

## 完整示例

### LDA任务示例
```bash
# 使用协作注意力融合的LDA任务
python main.py \
  --task_type LDA \
  --fusion_strategy co_attention \
  --co_hidden_dim 128 \
  --epochs 100 \
  --lr 1e-4 \
  --batch 32

# 使用混合策略的LDA任务
python main.py \
  --task_type LDA \
  --fusion_strategy hybrid \
  --fusion_weight 0.6 \
  --epochs 200 \
  --lr 5e-4
```

### MDA任务示例
```bash
# 使用混合策略，更注重协作注意力的MDA任务
python main.py \
  --task_type MDA \
  --fusion_strategy hybrid \
  --fusion_weight 0.3 \
  --epochs 150 \
  --lr 2e-4 \
  --hidden1 256 \
  --hidden2 128
```

### LMI任务示例
```bash
# 使用自注意力融合的LMI任务
python main.py \
  --task_type LMI \
  --fusion_strategy self_attention \
  --epochs 100 \
  --lr 1e-4 \
  --dropout 0.2
```

## 参数参考表

| 参数 | 可选值 | 默认值 | 说明 |
|------|--------|--------|------|
| `--fusion_strategy` | `self_attention`, `co_attention`, `hybrid` | `self_attention` | 融合策略类型 |
| `--fusion_weight` | `0.0-1.0` | `0.5` | 混合策略中的自注意力权重 |
| `--co_hidden_dim` | `正整数` | `None` | 协作注意力的隐藏维度 |

## 特性优势

### 热插拔支持
- **运行时切换**: 可以在训练过程中动态切换融合策略
- **无缝集成**: 不影响其他模块，完全向后兼容
- **参数灵活**: 每种策略都有专门的参数配置

### 性能对比
| 策略 | 特点 | 适用场景 |
|------|------|----------|
| `self_attention` | 原始实现，速度快 | 标准任务，基线对比 |
| `co_attention` | 双向交互，语义丰富 | 复杂关系建模 |
| `hybrid` | 平衡性能与效果 | 大多数场景，推荐使用 |

## 注意事项

1. **向后兼容**: 不指定 `--fusion_strategy` 时，默认使用 `self_attention`
2. **参数验证**: 所有参数都会在启动时进行有效性检查
3. **内存使用**: `co_attention` 和 `hybrid` 策略可能需要更多内存
4. **训练时间**: 不同策略的训练时间可能略有差异

## 故障排除

### 常见问题

**Q: 出现 "Unknown strategy_type" 错误**
A: 检查 `--fusion_strategy` 参数是否为三种有效值之一

**Q: 协作注意力效果不明显**
A: 尝试调整 `--co_hidden_dim` 参数，设置为输入维度的2倍

**Q: 混合策略效果不佳**
A: 尝试不同的 `--fusion_weight` 值，从0.3到0.7之间测试

**Q: 训练速度变慢**
A: `self_attention` 策略最快，`co_attention` 次之，`hybrid` 最慢

```bash

```
