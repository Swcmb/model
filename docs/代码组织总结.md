## 🏗️ 代码结构概览

### 1. 工厂模式架构 (`AttentionFactory`)

```python
class AttentionFactory:
    """注意力机制工厂类"""
    
    @staticmethod
    def create_co_attention(dim, config_str, **kwargs):
        """创建协作注意力模块"""
        
    @staticmethod  
    def create_fusion_attention(dim, config_str, **kwargs):
        """创建融合注意力模块"""
        
    @staticmethod
    def get_available_configurations():
        """获取所有可用配置"""
```

### 2. 协作注意力层次结构

```
协作注意力基类
├── PairwiseCoAttention                 # 基础协作注意力
├── TransformerPairwiseCoAttention      # Transformer风格
├── MultiHeadPairwiseCoAttention       # 多头协作注意力
└── GateMultiHeadPairwiseCoAttention   # 门控多头协作注意力
```

### 3. 融合策略层次结构

```
融合策略基类 (FusionStrategy)
├── SelfAttentionFusion                # 自注意力融合
├── CoAttentionFusion                  # 协作注意力融合
├── HybridFusion                      # 混合融合
├── MultiHeadTransformerPairwiseCoAttention  # Transformer多头
└── GateMultiHeadTransformerPairwiseCoAttention  # 门控Transformer
```

## 📊 注意力机制对比

| 类型 | 复杂度 | 特点 | 推荐场景 |
|------|---------|------|----------|
| `PairwiseCoAttention` | O(d²) | 简单高效 | 小数据集 |
| `TransformerPairwiseCoAttention` | O(d²+dh) | Transformer架构 | 中等复杂度 |
| `MultiHeadPairwiseCoAttention` | O(d²h) | 多头并行 | 高维特征 |
| `GateMultiHeadPairwiseCoAttention` | O(d²h+dg) | 门控控制 | 精细建模 |

## 🚀 使用方式

### 1. 基础配置
```bash
# 自注意力融合
python main.py --fusion_strategy self_attention --fusion_heads 4

# 协作注意力
python main.py --use_co_attention --co_attention_type transformer
```

### 2. 高级配置
```bash
# 门控多头
python main.py --attention_config gated_transformer[num_heads=8,headwise_gate=true]

# 混合融合
python main.py --fusion_strategy hybrid[fusion_weight=0.7,co_attention_type=transformer]
```

### 3. 编程接口
```python
# 工厂模式创建
co_attn = AttentionFactory.create_co_attention(
    dim=256, 
    config_str="transformer[num_heads=8,dropout=0.2]"
)

# 融合创建
fusion = AttentionFactory.create_fusion_attention(
    dim=256,
    config_str="gated_transformer[num_heads=8]"
)
```

## 📈 性能优化建议

### 1. 头数选择
- **低维 (≤128)**: 2-4头
- **中维 (256-512)**: 4-8头  
- **高维 (>512)**: 8-16头

### 2. 门控策略
- **小数据集**: `headwise_gate=true`
- **大数据集**: `elementwise_gate=true`

### 3. 融合权重
- **表示学习优先**: `fusion_weight=0.7`
- **交互建模优先**: `fusion_weight=0.3`
