# 协作注意力使用指南

## 概述

本项目现在支持通过命令行参数控制是否使用协作注意力融合策略，以及在使用时选择TransformerPairwiseCoAttention还是PairwiseCoAttention。

## 命令行参数

### 控制是否使用协作注意力

```bash
--use_co_attention <true|false>
```

- 默认值: false
- 作用: 控制是否强制使用协作注意力融合策略

### 控制协作注意力类型

```bash
--co_attention_type <transformer|pairwise>
```

- 默认值: transformer
- 作用: 当使用协作注意力时，指定使用哪种类型的协作注意力
- 可选值:
  - transformer: 使用TransformerPairwiseCoAttention（默认）
  - pairwise: 使用PairwiseCoAttention

## 使用示例

### 1. 强制使用协作注意力（默认使用Transformer类型）

```bash
python main.py --use_co_attention true
```

### 2. 强制使用协作注意力并指定使用Pairwise类型

```bash
python main.py --use_co_attention true --co_attention_type pairwise
```

### 3. 强制使用协作注意力并指定使用Transformer类型

```bash
python main.py --use_co_attention true --co_attention_type transformer
```

### 4. 使用传统的融合策略选择方式

```bash
# 使用自注意力融合（默认）
python main.py

# 使用协作注意力融合（传统方式）
python main.py --fusion_strategy co_attention

# 使用混合融合策略
python main.py --fusion_strategy hybrid
```

## 参数优先级

当同时设置了`--use_co_attention`和`--fusion_strategy`时，`--use_co_attention true`具有更高的优先级，会覆盖`--fusion_strategy`的设置。

## 特性说明

### TransformerPairwiseCoAttention
- 基于Transformer的实现
- 包含多头注意力机制
- 具有残差连接和LayerNorm
- 包含FFN（前馈网络）层

### PairwiseCoAttention
- 基础的协作注意力实现
- 相对简单但有效的注意力机制
- 计算效率更高
