# 注意力机制重构总结

## 🎯 重构目标

将原有的硬编码注意力机制重构为支持命令行参数化配置的工厂模式，实现注意力机制的热插拔和灵活配置。

## ✅ 完成的功能

### 1. 工厂模式架构

#### AttentionFactory 类
- **创建协作注意力**: `create_co_attention(dim, config_str, **kwargs)`
- **创建融合注意力**: `create_fusion_attention(dim, config_str, **kwargs)`
- **参数解析**: `_parse_params(params_str)` - 支持类型自动转换
- **配置查询**: `get_available_configurations()` - 获取所有可用配置

#### 支持的配置字符串语法
```bash
# 基础配置
transformer
pairwise
multihead

# 带参数配置
transformer[num_heads=8,dropout=0.2,use_gelu=true]
gated_multihead[num_heads=4,headwise_gate=true,elementwise_gate=false]

# 嵌套配置
co_attention[co_attention_type=transformer[num_heads=8]]
```

### 2. 支持的注意力机制

#### 协作注意力类型
1. **PairwiseCoAttention** - 基础成对协作注意力
2. **TransformerPairwiseCoAttention** - Transformer风格协作注意力
3. **MultiHeadPairwiseCoAttention** - 多头协作注意力
4. **GateMultiHeadPairwiseCoAttention** - 门控多头协作注意力

#### 融合策略类型
1. **SelfAttentionFusion** - 自注意力融合
2. **CoAttentionFusion** - 协作注意力融合
3. **HybridFusion** - 混合融合（自注意力+协作注意力）
4. **MultiHeadTransformerPairwiseCoAttention** - Transformer多头融合
5. **GateMultiHeadTransformerPairwiseCoAttention** - 门控Transformer融合

### 3. 命令行参数系统

#### 新增参数
```bash
# 高级配置
--attention_config                 # 高级注意力配置字符串
--use_multihead                   # 启用多头注意力
--headwise_gate                   # 头级门控
--elementwise_gate                # 元素级门控
--transformer_style               # Transformer风格

# 协作注意力
--use_co_attention               # 启用协作注意力
--co_attention_type              # 协作注意力类型和参数
--co_hidden_dim                  # 协作注意力隐藏层维度

# 扩展原有参数
--fusion_strategy                # 现在支持工厂模式配置
--fusion_heads                   # 注意力头数
--fusion_weight                  # 混合融合权重
```

## 🚀 使用示例

### 基础使用
```bash
# 自注意力融合
python main.py --fusion_strategy self_attention --fusion_heads 4

# 协作注意力融合
python main.py --use_co_attention --co_attention_type transformer

# 混合融合
python main.py --fusion_strategy hybrid --fusion_weight 0.7
```

### 高级配置
```bash
# 门控多头Transformer
python main.py --attention_config gated_transformer[num_heads=8,headwise_gate=true]

# 复杂嵌套配置
python main.py --fusion_strategy hybrid[fusion_weight=0.6,co_attention_type=transformer[num_heads=8]]
```

### 快速配置组合
```bash
# 启用多头和门控
python main.py --use_multihead --headwise_gate --elementwise_gate

# Transformer风格协作注意力
python main.py --use_co_attention --transformer_style --co_attention_type transformer[num_heads=8]
```

## 📈 性能建议

### 头数选择
- 特征维度 ≤ 128: 2-4头
- 特征维度 256-512: 4-8头
- 特征维度 > 512: 8-16头

### 门控使用
- 小数据集: `headwise_gate=true`
- 大数据集: `elementwise_gate=true`

### 混合权重
- 优先表示学习: `fusion_weight=0.7`
- 优先交互建模: `fusion_weight=0.3`
