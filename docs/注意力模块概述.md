## 注意力机制分类

### 1. 协作注意力 (Co-Attention)
实现两个实体间的双向信息交互

#### 🔹 PairwiseCoAttention (基础成对协作注意力)
- **特点**: 最基础的协作注意力实现
- **机制**: A→B 和 B→A 双向注意力计算
- **适用**: 简单任务，快速原型

```python
# 使用方式
co_attn = PairwiseCoAttention(dim=256)
A_out, B_out = co_attn(A, B)
```

#### 🔹 TransformerPairwiseCoAttention (Transformer风格协作注意力)
- **特点**: 结合Transformer架构的协作注意力
- **机制**: 多头注意力 + LayerNorm + FFN
- **适用**: 中等复杂度任务

```python
# 使用方式
co_attn = TransformerPairwiseCoAttention(
    dim=256, 
    num_heads=8, 
    dropout=0.1
)
A_out, B_out = co_attn(A, B)
```

#### 🔹 MultiHeadPairwiseCoAttention (多头协作注意力)
- **特点**: 标准多头注意力机制
- **机制**: 经典scaled dot-product attention
- **适用**: 需要并行处理的高维特征

```python
# 使用方式
co_attn = MultiHeadPairwiseCoAttention(
    dim=256, 
    num_heads=8
)
A_out, B_out = co_attn(A, B)
```

#### 🔹 GateMultiHeadPairwiseCoAttention (门控多头协作注意力)
- **特点**: 带门控机制的多头注意力
- **机制**: 头级门控 + 元素级门控
- **适用**: 需要精细信息控制的大数据集

```python
# 使用方式
co_attn = GateMultiHeadPairwiseCoAttention(
    dim=256, 
    num_heads=8,
    headwise_attn_output_gate=True,  # 头级门控
    elementwise_attn_output_gate=False  # 元素级门控
)
A_out, B_out = co_attn(A, B)
```

### 2. 融合策略 (Fusion Strategy)
将协作注意力结果融合为最终表示

#### 🔹 SelfAttentionFusion (自注意力融合)
- **特点**: 基于多头自注意力的融合
- **机制**: 内部自注意力 + 前馈网络
- **输出**: 拼接后的 [B, 2H] 表示

```python
# 使用方式
fusion = SelfAttentionFusion(hidden_dim=256, heads=4)
output = fusion(e1, e2)  # [B, 512]
```

#### 🔹 CoAttentionFusion (协作注意力融合)
- **特点**: 直接使用协作注意力融合
- **机制**: 协作注意力 + 特征拼接
- **输出**: 拼接后的 [B, 2H] 表示

```python
# 使用方式
fusion = CoAttentionFusion(
    hidden_dim=256,
    co_attention_type='transformer'
)
output = fusion(e1, e2)  # [B, 512]
```

#### 🔹 HybridFusion (混合融合)
- **特点**: 自注意力 + 协作注意力混合
- **机制**: 加权融合两种注意力结果
- **输出**: 加权融合的 [B, 2H] 表示

```python
# 使用方式
fusion = HybridFusion(
    hidden_dim=256,
    fusion_weight=0.7,  # 70%自注意力, 30%协作注意力
    co_attention_type='transformer'
)
output = fusion(e1, e2)  # [B, 512]
```

#### 🔹 MultiHeadTransformerPairwiseCoAttention (Transformer多头融合)
- **特点**: 完整的Transformer架构融合
- **机制**: 自注意力 + 协作注意力 + 门控融合
- **输出**: 单一 [B, H] 表示

```python
# 使用方式
fusion = MultiHeadTransformerPairwiseCoAttention(
    dim=256, 
    num_heads=8,
    dropout=0.1
)
output = fusion(A, B)  # [B, 256]
```

#### 🔹 GateMultiHeadTransformerPairwiseCoAttention (门控Transformer融合)
- **特点**: 带门控的完整Transformer融合
- **机制**: 门控多头协作注意力 + 门控融合
- **输出**: 门控控制的 [B, H] 表示

```python
# 使用方式
fusion = GateMultiHeadTransformerPairwiseCoAttention(
    dim=256, 
    num_heads=8,
    headwise_attn_output_gate=True,
    elementwise_attn_output_gate=True
)
output = fusion(A, B)  # [B, 256]
```

## 关键技术细节

### 1. 注意力计算公式

#### 基础协作注意力
```python
# A → B 方向
Q_A = Wq_A @ A,  K_B = Wk_B @ B,  V_B = Wv_B @ B
attn_AB = softmax(Q_A @ K_B.T / sqrt(d_k))
A_out = A + proj_A(attn_AB @ V_B)

# B → A 方向 (对称)
Q_B = Wq_B @ B,  K_A = Wk_A @ A,  V_A = Wv_A @ A
attn_BA = softmax(Q_B @ K_A.T / sqrt(d_k))
B_out = B + proj_B(attn_BA @ V_A)
```

#### 多头注意力
```python
# 头分割
Q = view(Q, B, H, L, Dh)  # [B, H, L, Dh]
K = view(K, B, H, L, Dh)
V = view(V, B, H, L, Dh)

# 注意力计算
scores = Q @ K.transpose(-2, -1) / sqrt(Dh)  # [B, H, L, L]
attn = softmax(scores, dim=-1)
output = attn @ V  # [B, H, L, Dh]

# 头合并
output = transpose(output, 1, 2).contiguous().view(B, L, H*Dh)
```

### 2. 门控机制

#### 头级门控 (Headwise Gate)
```python
# 每个头一个门控标量
gate_scores = sigmoid(linear([H, 1]))  # [B, H, 1]
output = gated_output * gate_scores
```

#### 元素级门控 (Elementwise Gate)
```python
# 每个元素一个门控值
gate_scores = sigmoid(linear([H, Dh]))  # [B, H, Dh] 
output = gated_output * gate_scores
```

### 3. 残差连接与层归一化

```python
# Transformer风格
def transformer_block(x):
    # 自注意力 + 残差
    attn_out = self_attention(x)
    x = layer_norm(x + attn_out)
    
    # 前馈网络 + 残差
    ffn_out = feed_forward(x) 
    x = layer_norm(x + ffn_out)
    return x
```

## 性能对比

| 注意力类型 | 计算复杂度 | 内存占用 | 并行性 | 适用场景 |
|-----------|-----------|---------|--------|----------|
| PairwiseCoAttention | O(d²) | 低 | 中 | 简单任务 |
| TransformerPairwiseCoAttention | O(d² + d·h) | 中 | 高 | 中等复杂度 |
| MultiHeadPairwiseCoAttention | O(d²·h) | 中 | 高 | 高维特征 |
| GateMultiHeadPairwiseCoAttention | O(d²·h + d·g) | 高 | 高 | 精细控制 |

其中:
- d: 特征维度
- h: 注意力头数  
- g: 门控参数量

## 配置建议

### 🔹 根据数据规模选择

**小数据集 (< 10K 样本)**
```python
# 推荐: 简单协作注意力
co_attention_type = "pairwise"
fusion_strategy = "self_attention"
heads = 4
```

**中等数据集 (10K-100K 样本)**
```python
# 推荐: Transformer协作注意力
co_attention_type = "transformer"
fusion_strategy = "co_attention" 
heads = 8
dropout = 0.1
```

**大数据集 (> 100K 样本)**
```python
# 推荐: 门控多头注意力
co_attention_type = "gated_multihead"
fusion_strategy = "gated_transformer"
heads = 16
headwise_gate = True
elementwise_gate = True
```

### 🔹 根据特征维度选择

**低维特征 (≤ 128)**
```python
heads = 2-4
gate_type = "headwise"  # 头级门控更高效
```

**中维特征 (256-512)**
```python
heads = 4-8
gate_type = "headwise"  # 平衡效率
```

**高维特征 (> 512)**
```python
heads = 8-16
gate_type = "elementwise"  # 元素级门控更精细
```

### 🔹 根据任务复杂度选择

**简单分类任务**
```python
fusion_strategy = "self_attention"
use_co_attention = False
```

**复杂关系建模**
```python
fusion_strategy = "hybrid"
fusion_weight = 0.6  # 更多自注意力
use_co_attention = True
co_attention_type = "transformer"
```

**精细交互建模**
```python
fusion_strategy = "gated_transformer"
headwise_gate = True
elementwise_gate = True
```

## 工厂模式使用

### 基础使用
```python
from layer import AttentionFactory

# 创建协作注意力
co_attn = AttentionFactory.create_co_attention(
    dim=256, 
    config_str="transformer[num_heads=8,dropout=0.2]"
)

# 创建融合注意力
fusion = AttentionFactory.create_fusion_attention(
    dim=256,
    config_str="gated_transformer[num_heads=8,headwise_gate=true]"
)
```

### 参数解析
```python
# 配置字符串格式
config_str = "transformer[num_heads=8,dropout=0.2,use_gelu=true]"

# 自动解析为
params = {
    'num_heads': 8,
    'dropout': 0.2, 
    'use_gelu': True
}
```

### 嵌套配置
```python
# 协作注意力类型嵌套参数
config_str = "co_attention[co_attention_type=transformer[num_heads=8]]"

# 等价于
{
    'co_attention_type': 'transformer',
    'transformer_params': {'num_heads': 8}
}
```

## 命令行配置

### 快速配置
```bash
# 基础自注意力
python main.py --fusion_strategy self_attention

# 协作注意力
python main.py --use_co_attention --co_attention_type transformer

# 多头+门控  
python main.py --use_multihead --headwise_gate --elementwise_gate

# 高级配置字符串
python main.py --attention_config "gated_transformer[num_heads=8,headwise_gate=true]"
```

### 参数映射
| 命令行参数 | 工厂配置字符串 | 说明 |
|-------------|----------------|------|
| `--use_co_attention` | `co_attention` | 启用协作注意力 |
| `--use_multihead` | `multihead` | 启用多头注意力 |
| `--headwise_gate` | `headwise_gate=true` | 头级门控 |
| `--elementwise_gate` | `elementwise_gate=true` | 元素级门控 |
| `--attention_config` | 直接指定 | 高级配置字符串 |
