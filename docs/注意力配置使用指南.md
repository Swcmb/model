# 注意力机制配置使用指南

## 概述

本项目的注意力机制已重构为工厂模式，支持通过命令行参数灵活配置不同的注意力机制。所有注意力组件都支持热插拔和参数化配置。

## 支持的注意力机制

### 1. 协作注意力类型 (Co-Attention Types)

#### 基础协作注意力
- `pairwise` - 基础成对协作注意力
- `transformer` - Transformer风格协作注意力
- `multihead` - 多头协作注意力
- `gated_multihead` - 门控多头协作注意力

#### 参数化配置示例
```bash
# 基础Transformer协作注意力
--co_attention_type transformer

# 多头协作注意力，8个头
--co_attention_type multihead[num_heads=8]

# 门控多头，带头级门控
--co_attention_type gated_multihead[num_heads=4,headwise_gate=true]

# 带FFN和dropout的Transformer
--co_attention_type transformer[num_heads=8,dropout=0.2,use_gelu=true]
```

### 2. 融合策略类型 (Fusion Strategy Types)

#### 基础融合策略
- `self_attention` - 自注意力融合
- `co_attention` - 协作注意力融合
- `hybrid` - 混合融合（自注意力+协作注意力）
- `transformer_multihead` - Transformer多头融合
- `gated_transformer` - 门控Transformer融合

#### 参数化配置示例
```bash
# 标准自注意力融合
--fusion_strategy self_attention

# 协作注意力融合，使用Transformer协作
--fusion_strategy co_attention[co_attention_type=transformer]

# 混合融合，70%自注意力 + 30%协作注意力
--fusion_strategy hybrid[fusion_weight=0.7,co_attention_type=transformer]

# 门控Transformer多头融合
--fusion_strategy gated_transformer[num_heads=8,headwise_gate=true,elementwise_gate=true]
```

## 命令行使用示例

### 示例1: 基础配置
```bash
python main.py \
    --fusion_strategy self_attention \
    --fusion_heads 4 \
    --dropout 0.1
```

### 示例2: 协作注意力配置
```bash
python main.py \
    --fusion_strategy co_attention \
    --co_attention_type transformer \
    --fusion_heads 8 \
    --dropout 0.2
```

### 示例3: 混合注意力配置
```bash
python main.py \
    --fusion_strategy hybrid \
    --fusion_weight 0.6 \
    --co_attention_type transformer[num_heads=8,dropout=0.1] \
    --fusion_heads 4 \
    --dropout 0.1
```

### 示例4: 门控多头配置
```bash
python main.py \
    --fusion_strategy gated_transformer \
    --fusion_heads 8 \
    --dropout 0.2 \
    --headwise_gate true \
    --elementwise_gate false
```

## 参数说明

### 通用参数
- `--fusion_strategy`: 融合策略类型
- `--fusion_heads`: 注意力头数
- `--dropout`: Dropout概率

### 协作注意力参数
- `--co_attention_type`: 协作注意力类型
- `--co_hidden_dim`: 协作注意力隐藏层维度
- `--fusion_weight`: 混合融合的权重比例

### 门控参数
- `--headwise_gate`: 是否使用头级门控
- `--elementwise_gate`: 是否使用元素级门控

## 配置字符串语法

配置字符串格式：`type[param1=value1,param2=value2,...]`

### 支持的参数类型
- 布尔值：`true`/`false`
- 整数：`8`
- 浮点数：`0.1`
- 字符串：`transformer`

### 示例
```bash
# 简单配置
transformer

# 带参数配置
transformer[num_heads=8,dropout=0.2]

# 嵌套配置
co_attention[co_attention_type=transformer[num_heads=4]]
```

## 工厂方法API

### 创建协作注意力
```python
from layer import AttentionFactory

# 基础创建
co_attn = AttentionFactory.create_co_attention(
    dim=256, 
    config_str="transformer"
)

# 带参数创建
co_attn = AttentionFactory.create_co_attention(
    dim=256,
    config_str="transformer[num_heads=8,dropout=0.2]",
    use_gelu=True
)
```

### 创建融合注意力
```python
# 基础创建
fusion = AttentionFactory.create_fusion_attention(
    dim=256,
    config_str="self_attention"
)

# 复杂配置
fusion = AttentionFactory.create_fusion_attention(
    dim=256,
    config_str="hybrid[fusion_weight=0.7,co_attention_type=transformer]",
    heads=8,
    dropout=0.1
)
```

## 动态配置

支持运行时动态切换注意力机制：

```python
# 在FusionDecoder中切换策略
decoder = FusionDecoder(hidden_dim=256, decoder1_dim=128)
decoder.set_fusion_strategy("gated_transformer[num_heads=8]")
```

## 性能优化建议

1. **多头数量**: 根据特征维度选择合适的多头数量
   - 特征维度 ≤ 128: 2-4头
   - 特征维度 256-512: 4-8头  
   - 特征维度 > 512: 8-16头

2. **门控使用**: 
   - 小数据集：推荐`headwise_gate=true`
   - 大数据集：推荐`elementwise_gate=true`

3. **混合权重**:
   - 优先表示学习：`fusion_weight=0.7`（更多自注意力）
   - 优先交互建模：`fusion_weight=0.3`（更多协作注意力）
